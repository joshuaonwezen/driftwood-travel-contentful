# Driftwood Travel website

Next.js 16 site for a fictional tour operator, with Contentful as the CMS. Start with `README.md` (setup, scripts, routes) and `docs/content-model.md` (content types, URL rules, inventory, edge cases).

## Where things are

- `src/lib/contentful.ts`: Contentful Delivery/Preview clients and every query the site makes. Draft mode (`draftMode()`) switches to the Preview API.
- `src/lib/links.ts`: turns entries into URLs. Landing page paths come from the `parentPage` chain (`getLandingPageIndex`).
- `src/components/blocks/`: one component per section content type; `block-renderer.tsx` maps `sys.contentType.sys.id` to a component.
- `src/components/rich-text.tsx`: Contentful rich text rendering (embedded entries/assets, entry hyperlinks, tables).
- `src/types/contentful/`: generated by `npm run cf:types`; do not edit by hand.
- `contentful/migrations/`: the content model. Change the model by adding a new numbered migration, never by editing an applied one.
- `contentful/export/space.json`: full snapshot of the space; refresh with `npm run cf:export`.
- `scripts/seed/`: demo content generator. Entry IDs are derived from readable seed keys (`cfId("article:<slug>")`).

## Commands

- `npm run typecheck && npm run lint && npm run build` before committing.
- `npm run verify` checks the live space; `npm run crawl -- http://localhost:3000` checks a running site.
- Scripts read `.env.local` (never commit it). Contentful's free plan rate-limits the CMA; the SDK retries 429s automatically.
